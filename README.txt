XCMG NIGERIA WEBSITE PACKAGE

How to run locally:
1. Open the folder in VS Code.
2. Open index.html directly in a browser, or use Live Server for smoother preview.

How to deploy on Netlify:
1. Drag and drop the folder "xcmg-nigeria-site" into Netlify.
2. No build command needed.
3. Publish as a static site.

Structure:
- index.html
- css/global.css
- js/global.js
- pages/about.html
- pages/products.html
- pages/projects.html
- pages/contact.html
- images/*
